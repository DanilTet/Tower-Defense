# STRICT CONTEXT & TOKEN BUDGET RULES
1. ЗАПРЕЩЕНО вызывать чтение файла целиком, если в нём больше 120 строк.
2. При вызове инструмента просмотра файла параметр диапазона СТРОГО ограничен: EndLine - StartLine <= 80.
3. Для ознакомления со структурой ВСЕГДА читай заголовочный файл (.h), а не файл реализации (.cpp).
4. Любой поиск метода или переменной выполняется ИСКЛЮЧИТЕЛЬНО через `Select-String` / `grep -n`, после чего считываются только найденные 30-50 строк.
